# Titanic Survival Analysis

## Objective
To explore the Titanic dataset, identify patterns affecting survival, and present findings through visualizations.

## Dataset
Titanic dataset (loaded using Seaborn), 891 passengers originally, about 778 after cleaning.

## Tools Used
Python, Pandas, NumPy, Matplotlib, Seaborn, SciPy, Google Colab

## Task 2: Exploratory Data Analysis
- Asked meaningful questions before starting the analysis
- Explored data structure and data types
- Found and fixed missing values and duplicates
- Identified patterns and outliers
- Performed two hypothesis tests (Chi-Square and T-Test)

## Task 3: Data Visualization
- Created 5 charts covering gender, class, age and fare
- Built a mini dashboard combining key visuals
- Wrote a data story connecting all findings

## Key Findings
- Female passengers had a survival rate of 73.9%, compared to 21.6% for males
- 1st class passengers had the highest survival rate (62.7%)
- Survivors paid an average fare of 49.89, more than double the 23.94 paid by non-survivors
- Gender and survival are strongly related (p = 2.37e-46)
- Survivors paid a significantly higher fare (p = 6.85e-10)
